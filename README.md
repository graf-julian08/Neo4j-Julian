# Neo4j Julian

Graphendatenbank Projekt fuer Geopath-Analysen und Knotenverbindungen mit Neo4j.

## Funktionalitaeten
- Uebersichtlicher Code und strukturierte Aufteilung der Komponenten.
- Einfache Integration und Anpassung an bestehende Systeme.

## Nutzung
Fuehre die Skripte im Geopath Ordner aus, um Neo4j Daten zu verarbeiten.
